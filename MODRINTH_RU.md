**Copycat Roller** — небольшой NeoForge-аддон, добавляющий совместимость
Mechanical Roller из Create с тонкими строительными блоками Copycats+.

Каток следует точной высоте прямых, диагональных и кривых железнодорожных
путей, позволяя создавать поверхность с шагом 1/8 блока.

## Возможности

В слот фильтра Mechanical Roller можно поместить:

- Copycat Layer
- Copycat Half Layer
- Copycat Slope Layer
- Zinc Ingot

Совместимость активна только в режиме катка **Fill**
(`STRAIGHT_FILL`). `TUNNEL_PAVE`, `WIDE_FILL` и все остальные материалы
сохраняют штатное поведение Create.

## Автоматический режим с цинком

Поместите **Zinc Ingot** в фильтр катка, чтобы форма блока выбиралась
автоматически:

- если обе половины будущей поверхности имеют одинаковую высоту, каток
  устанавливает обычный Copycat Layer;
- если высоты различаются, устанавливается Copycat Half Layer с независимым
  количеством слоёв для каждой стороны.

Это убирает лишний центральный шов на ровных участках, сохраняя более точную
форму Half Layer на переходах высоты. Также это помогает избежать проблем с
текстурами Copycats.

Расходуемый цинк должен находиться в установленном на контрапции хранилище.
Как и у обычного Mechanical Roller, предмет в самом слоте фильтра не
расходуется.

### Расход цинка

Расход соответствует рецептам Copycats+:

- 1 Zinc Ingot = 8 обычных Layer;
- 1 Zinc Ingot = 16 Half Layer;
- 1 обычный Layer равен двум Half Layer по стоимости.

Неиспользованный материал сохраняется в инвентаре контрапции настоящими
предметами `copycat_half_layer` и автоматически расходуется при следующих
установках.

Например, обычный Layer с `layers=3` использует 3 из 8 Layer, полученных из
одного слитка. Оставшаяся стоимость возвращается в виде 10 Half Layer.

Если в инвентаре недостаточно места для остатка, конкретная установка
полностью отменяется: цинк не теряется, лишние предметы не выбрасываются, а
мир остаётся неизменным.

## Точная поверхность пути

Когда каток входит в состав поезда, аддон сохраняет дробную высоту пути до
того, как Create её округлит:

- прямые участки интерполируются по реальной геометрии TrackEdge;
- кривые используют покрытие Create, сохраняя исходный дробный Y;
- ширина пути, steering и X/Z-покрытие не изменяются;
- Half Layer учитывает высоту над каждой половиной блока;
- состояния, которые выступали бы сквозь рельсы, не устанавливаются;
- неподходящие Slope Layer могут быть пропущены, чтобы не создавать «пилу».

По умолчанию создаётся только верхняя частичная поверхность. Полные
Copycat-блоки под ней не устанавливаются, а ровный путь, совпадающий с целой
Y-границей, не расходует материал.

Вне железнодорожного состава точная геометрия пути недоступна. Поэтому аддон
использует обычную целевую позицию Mechanical Roller и устанавливает полное
состояние выбранного блока.

## Расход Copycat-блоков

Если один из трёх Copycat-блоков выбран напрямую, каток расходует именно
этот предмет:

| Состояние | Расход |
| --- | ---: |
| Обычный Layer с `layers=N` | `N` |
| Полный обычный Layer | `8` |
| Slope Layer с `layers=N` | `N` |
| Half Layer | `negative_layers + positive_layers` |
| Полный Half Layer | `16` |
| Наращивание существующего пустого слоя | Только положительная разница |
| Повторный проход по готовому состоянию | `0` |

Существующие Copycat-блоки с назначенным игроком материалом никогда не
перезаписываются.

Каждая установка атомарна. Если предметов недостаточно для полной операции,
не изменяются ни блок, ни инвентарь.

## Конфигурация

После первого запуска создаётся файл:

```text
config/copycat_roller-common.toml
```

Настройки по умолчанию:

```toml
[paving]
roundingDirection = "DOWN"
surfaceOnly = true
fillDepthBlocks = 1
slopeMaxVerticalError = 0.25
```

### `roundingDirection`

- `DOWN` — округляет к предыдущей ступени 1/8:
  `(0, 1/8] → 0`, `(1/8, 2/8] → 1`, …, `(7/8, 1] → 7`;
- `UP` — округляет вверх, чтобы избежать вертикального зазора:
  `(0, 1/8] → 1`, …, `(7/8, 1) → 8`.

### `surfaceOnly`

- `true` — устанавливает только верхнюю частичную ячейку поверхности;
- `false` — включает заполнение вниз полными блоками.

### `fillDepthBlocks`

Управляет глубиной заполнения вниз при `surfaceOnly=false`. Допустимые
значения: `1..512`. Результат также ограничивается серверной настройкой
Create `rollerFillDepth`.

### `slopeMaxVerticalError`

Задаёт максимально допустимый вертикальный зазор между краем Slope Layer и
профилем пути. Меньшее значение создаёт более точную, но потенциально более
разреженную поверхность.
