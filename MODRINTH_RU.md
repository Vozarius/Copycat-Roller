# Copycat Roller

Mechanical Roller из Create — теперь со слоями Copycats+.

Стройте плавное основание железной дороги вдоль прямых, диагональных и кривых
путей с шагом 1/8 блока.

## Возможности

- Точная укладка Copycat-блоков вдоль железнодорожных путей
- Поддержка Layer, Half Layer и Slope Layer
- Автоматический выбор Layer или Half Layer с помощью цинкового слитка
- Обычные блоки одновременно заполняют Copycat-блоки и укладываются в пустых местах
- Безопасный расход предметов без скрытого баланса материалов

## Фильтры

Поместите в фильтр Mechanical Roller один из следующих предметов:

- **Copycat Layer**
  - Регулируемая поверхность с шагом 1/8 блока
- **Copycat Half Layer**
  - Независимая высота с каждой стороны
- **Copycat Slope Layer**
  - Плавный склон там, где существует подходящее состояние
- **Zinc Ingot**
  - Автоматически выбирает Layer или Half Layer
- **Любой поддерживаемый блок**
  - Назначает свой материал Copycat-блокам и продолжает штатную укладку Create

Функции аддона активны в режиме **Fill** (`STRAIGHT_FILL`). Tunnel и Wide Fill
сохраняют штатное поведение Create.

## Расход предметов

- `layers=N` расходует `N` предметов Layer или Slope Layer.
- Цена Half Layer равна сумме слоёв двух его сторон.
- Один цинковый слиток создаёт до 8 Layer или 16 Half Layer. Остаток
  сохраняется настоящими предметами Half Layer.
- Заполнение Copycat расходует один блок материала на каждую пустую часть.
  Обычная укладка дополнительно расходует блоки по правилам Create.

Назначенные игроком материалы никогда не перезаписываются. Если предметов не
хватает на полную операцию, она безопасно отменяется.

## Требования

- Minecraft 1.21.1
- NeoForge 21.1.x
- Create 6
- Copycats+ 3.0.4
- Java 21

Установите зависимости и поместите Copycat Roller в папку `mods` на клиенте и
сервере.

## Конфигурация

В конфиге можно изменить округление высоты, укладку только верхней
поверхности, глубину заполнения Copycat и точность Slope Layer. По умолчанию
каток округляет вниз и ставит только ближайшую верхнюю поверхность Copycat.
