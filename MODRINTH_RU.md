# Copycat Roller

Mechanical Roller из Create — теперь с Copycats+.

Стройте плавные основания железных дорог вдоль прямых, диагональных и кривых
путей с шагом 1/8 блока.

## Возможности

- Укладка Layer, Half Layer и Slope Layer
- Автоматический выбор Layer/Half Layer с помощью цинка
- Полублочные склоны из Copycat Byte в режиме Wide Fill
- Обычные блоки заполняют Copycat-блоки и продолжают штатную укладку Create
- Поддержка совместимых модов на фильтры Roller
- Поддержка творческих ящиков Create
- Безопасный и точный расход предметов

В обычном режиме **Fill** поместите поддерживаемый Copycat или цинковый слиток
в фильтр Roller. В режиме **Wide Fill** каждый каток сохраняет обычное
центральное заполнение. Точные профили всех активных катков ряда сначала
объединяются в защищённую центральную маску, поэтому Copycat Byte не могут
занять места, предназначенные для обычных блоков. Склоны строят только два
крайних катка — каждый со своей внешней стороны. На поворотах каждый уровень
следует реальной локальной касательной и остаётся соединённым; открытые торцы
короткого профиля обрезаются, а необходимые опоры сохраняются. Внешняя сторона
определяется по соседним профилям катков, поэтому поворот вагона не создаёт
второй склон на другом удалении от рельсов. Первый Copycat Byte находится на
высоте центрального блока, затем каждые полблока склон
опускается на полблока. Дальность совпадает со штатным Wide Fill.

Один цинковый слиток равен 8 Layer, 16 Half Layer или 8 Copycat Byte. Остаток
возвращается настоящими предметами; если полную стоимость нельзя оплатить или
остаток некуда положить, операция отменяется. Творческие ящики Create могут
бесконечно подавать Copycat-блоки, цинк и копируемые материалы. Материалы,
назначенные игроком, не перезаписываются.

## Требования

- Minecraft 1.21.1
- NeoForge 21.1.200+
- Create 6
- Copycats+ 3.0.x (tested with 3.0.9)
- Java 21

Установите Copycat Roller на клиент и сервер. Аддон не изменяет JAR-файлы
Create и Copycats+.
