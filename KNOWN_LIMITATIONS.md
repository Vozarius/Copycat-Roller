# Известные ограничения

1. Совместимость намеренно ограничена Minecraft 1.21.1, Create 6.0.11 и
   Copycats+ 3.0.4. Диапазоны зависимостей не допускают молчаливое применение
   к следующему релизу, а `require=1` останавливает запуск при изменившейся
   сигнатуре Create.

2. Точный профиль доступен только для железнодорожного состава, когда
   `createHeightProfileForTracks()` возвращает `PaveTask`. У обычной
   движущейся контрапции нет геометрии пути, поэтому используется штатная
   координата Roller и только полное состояние выбранного типа.

3. По умолчанию `surfaceOnly=true`: под верхней частичной ячейкой опорные
   блоки не создаются. Поэтому Copycat может визуально «висеть» в воздухе,
   если под ним нет существующего основания. Прежнее заполнение доступно
   через `surfaceOnly=false`; только в нём применяются `fillDepthBlocks` и
   лимит `rollerFillDepth + 1` Create.

4. В режиме `DOWN` аддон намеренно может оставить зазор меньше либо равный
   1/8 блока: это выбранная пользователем семантика округления вниз.

5. Half Layer и Slope Layer имеют только горизонтальные направления X/Z.
   На диагонали выбирается доминирующая составляющая локальной касательной
   (при равенстве — X), поэтому одна ячейка не может иметь диагональный шов
   или диагональный `facing`. X/Z-покрытие Create при этом не меняется.

6. Геометрия Slope Layer определяется восемью штатными состояниями Copycats+.
   Их уклоны не параллельны друг другу. Аддон ставит только состояние,
   которое целиком лежит под профилем и укладывается в
   `slopeMaxVerticalError`; остальные ячейки намеренно пропускаются. Меньшее
   значение даёт более точную, но более разреженную поверхность, большее —
   более плотную, но ступенчатую.

7. Растеризация Bezier повторяет внутренний LUT/segment traversal
   `TrackPaverV2` 6.0.11. Это локализованное дублирование геометрии требуется,
   потому что публичный `PaveTask` уже содержит округлённый Y.

8. `RollingMode` в Create 6.0.11 package-private. Используется
   централизованный ordinal `STRAIGHT_FILL=1`; обязательный GameTest
   проверяет имена и порядок всех трёх enum-значений.

9. Mounted storage Create работает синхронно на серверном треде. Между
   отдельной симуляцией и точным реальным `ItemHelper.extract` нет
   межпоточного окна. Если нестандартный `IItemHandler` нарушит контракт или
   мир отклонит уже профинансированную установку, аддон откатывает блок и
   возвращает извлечённое; остаток, который уже нельзя вставить, безопасно
   выбрасывается в мире и логируется.

10. Автоматический режим использует точный ID `create:zinc_ingot`
    (`zink_ingot` в registry не существует). Сдача хранится настоящими
    предметами `copycats:copycat_half_layer`. Если после извлечения одного
    слитка в mounted storage не освобождается слот и существующий стек
    Half Layer не принимает всю сдачу, установка целиком отменяется. Аддон
    намеренно не хранит скрытый баланс и не выбрасывает штатную сдачу в мир.

11. GameTests интегрируют реальные registry, block entity, mixins,
   `TrackPaverV2` и dedicated server. Операции расхода и установки вызывают
   сервис напрямую, чтобы тесты не зависели от тайминга полностью собранного
   и движущегося поезда; X/Z-профиль прямой/диагонали/Bezier проверяется
   отдельно против реального `PaveTask` Create.
